# AI use

I built this with Claude Code (Anthropic) as an AI coding agent, which the challenge allows. I set the goal, the top-level plan and the constraints (ex. everything private and local, local speech models, a design unlike the usual stack) and approved the design before the build. The agent proposed the architecture and the alternatives in the decision log, wrote the code and the tests, ran the MELD audio extraction, the training, the evaluation and the container benchmarks, recorded the demo log in [results/demo_log.jsonl](results/demo_log.jsonl), and drafted these documents. I decided which open calls to hand to the agent, and it made them (ex. the reply lines, and the endpoint silence from the pause measurements in [results/](results/)). I asked for the optional extension: the face as a third input, a streamed reply and reinforcement learning. The agent designed and built it, ran the video extraction, the training, the evaluation, the benches and the demo ([results/demo_tav_log.jsonl](results/demo_tav_log.jsonl)), and drafted its parts of these documents. It wrote the decision rules for the deployed choices and the test claims before those runs. Some prompt choices on dev and the definitions of the generator choice rule were revised after preliminary runs. I reviewed the decisions, and I can explain and change any part of it. The live microphone demo, the camera session and the laptop measurements are mine to run ([docs/runbook_laptop.md](docs/runbook_laptop.md)). Every measured number in this repository was produced by the scripts in it.
