# AI use

I built this with Claude Code (Anthropic) as an AI coding agent, which the challenge allows. I set the goal and the constraints (ex. everything private and local, local speech models, a design that is not the usual stack) and approved the design before the build. The agent proposed the architecture and the alternatives in the decision log, wrote the code and the tests, ran the training, the evaluation and the container benchmarks, recorded the demo log in [results/demo_log.jsonl](results/demo_log.jsonl), and drafted these documents. I reviewed the decisions, and the open calls are mine (ex. the reply lines and the endpoint silence). The live microphone demo and the laptop measurements are mine to run ([docs/runbook_laptop.md](docs/runbook_laptop.md)). I can explain and change any part of it. Every number in this repository was produced by the scripts in it.
