# AI use

I built this with Claude Code (Anthropic) as an AI coding agent, which the challenge allows. I set the goal, the top-level plan of attack and the constraints (ex. everything private and local, local speech models, a design unlike the usual stack) and approved the design before the build. The agent proposed the architecture and the alternatives in the decision log, wrote the code and the tests, ran the MELD audio extraction, the training, the evaluation and the container benchmarks, recorded the demo log in [results/demo_log.jsonl](results/demo_log.jsonl), and drafted these documents. I decided which open calls to hand to the agent, and it made them (ex. the reply lines, and the endpoint silence from the pause measurements in [results/](results/)). I reviewed the decisions, and I can explain and change any part of it. The live microphone demo and the laptop measurements are mine to run ([docs/runbook_laptop.md](docs/runbook_laptop.md)). Every number in this repository was produced by the scripts in it.
